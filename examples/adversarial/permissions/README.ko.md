# 적대적 권한 상태 픽스처

이 픽스처는 Claude Code와 Codex의 제한적인 기준 상태와 이후의 자율성 확대를
모델링합니다. 모든 자격 증명, 명령 인수, 경로 및 호스트명은 비활성 테스트
데이터입니다. `.invalid` 호스트명은 공개 인터넷에서 해석될 수 없습니다.

평가는 다음을 검증합니다.

- 제한적 설정도 안전 인증으로 표현하지 않고 검토 가능한 상태로 유지
- 자동 셸, 네트워크, 파일 시스템 및 서브에이전트 권한 확대 감지
- 권한 상태 비교가 `needs-review`를 반환
- 검사, 스냅샷 또는 차이 출력에 설정 값과 경로 값이 나타나지 않음

이 픽스처는 외부 시스템에 대한 보안 테스트를 허가하지 않으며 실제 사용자
설정을 재현하지 않습니다.
